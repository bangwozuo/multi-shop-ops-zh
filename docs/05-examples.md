
夏季冰丝防晒衣 男女同款 轻薄透气 UPF50+ 防晒外套 可拆卸帽檐

2. **冰丝凉感材质** — 锦纶 + 氨纶混纺，客服可提供成分表

## 合规扫描

- 结论：**通过**
- 违规词：无（已规避「最好」「第一」「国家级」等极限词）

### 示例 3：库存水位计算

**能力**：销量速率+在途→安全水位

**输入**：

```json
{
  "params": {
    "售价": 68,
    "成本": 22,
    "平台扣点": 0.05
  }
}
```

**输出**：

## 计算结果

**结论**：扣点后净毛利 **37.2 元/单**，毛利率 **54.7%**

## 计算明细

| 项目 | 数值 | 说明 |
|------|------|------|
| 售价 | ¥68.00 | 含税 |
| 成本 | ¥22.00 | 采购成本 |
| 平台扣点 | ¥3.40 | 5% 抽成 |
| 配送/包材 | ¥5.40 | 均摊 |
| **净毛利** | **¥37.20** | — |
| 毛利率 | 54.7% | 净毛利 / 售价 |

## 假设说明

- 平台抽成按 5% 计算（实际费率请以平台规则为准）
- 配送与包材为月均摊值
- 未计入人力成本，若计入需另行测算

**资产位置**：`skills/stock-level-calculate/`
