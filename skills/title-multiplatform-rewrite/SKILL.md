# 标题多平台改写

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_ecom_04_sk02` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 多店运营官 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | ★★★★★（⑦共用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

同一卖点按各平台搜索逻辑改写

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `product_info` | object | ✅ | 商品信息（名称、材质、规格、卖点） |

## 输出规格

上架与标题优化

- `title`：含主关键词的标题，标注字数
- `selling_points`：按优先级排列的具体卖点
- `keywords`：关键词与投放位置
- `compliance_scan`：极限词、违禁词检查结果

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "product_info": "商品：晨露 316 不锈钢保温杯（型号 CL-BW500）。规格：500ml，杯身高 22cm，口径 5.5cm，重量 320g，颜色：雾灰白 / 薄暮蓝 / 岩黑。核心卖点：316L 医用级不锈钢内胆；真空镀铜保温层，官方实测 6 小时水温仍 ≥ 55℃（25℃室温、95℃注水条件）；杯口旋拧密封，倒置不漏；弹跳开盖单手可开。目标关键词：保温杯、316不锈钢保温杯、大容量保温杯、办公保温杯",
  "platform": "淘宝"
}

```

**输出**：

```markdown
**AI 生成内容**

## 优化后标题

晨露316不锈钢保温杯500ml大容量男女办公弹跳盖便携水杯（30 字，符合淘宝 30 字上限，主关键词「316不锈钢保温杯」置于前段）

## 卖点清单

1. 316L 医用级不锈钢内胆——对应目标关键词「316不锈钢保温杯」，是搜索热度核心词。
2. 真空镀铜保温层，6 小时水温 ≥ 55℃（25℃室温、95℃注水实测条件）——放在主图第 2 张与详情首屏。
3. 杯口旋拧密封、倒置不漏——针对通勤与车载场景。
4. 弹跳开盖单手可开——针对办公与驾驶场景。
5. 500ml 大容量三色可选（雾灰白/薄暮蓝/岩黑）——覆盖「大容量保温杯」长尾词。

## 关键词布局

| 关键词 | 类型 | 建议位置 |
|---|---|---|
| 保温杯 | 主类目词 | 标题前段与类目属性 |
| 316不锈钢保温杯 | 主搜索词 | 标题最前段（已置于第 3-11 字位） |
| 大容量保温杯 | 长尾词 | 标题中段 |
| 办公保温杯 | 场景长尾词 | 标题中后段 + 直通车词包 |
| 弹跳盖保温杯 | 属性长尾词 | 标题后段 + SKU 属性 |

## 合规扫描

1. 未检出「最好」「第一」「100%」等《广告法》极限词；保温时长数据已标注实测条件（25℃室温、95℃注水），避免绝对化表述。
2. 「医用级」为内胆材质等级描述，建议人工确认是否需补充食品接触材料检测报告编号，以降低描述争议风险。
3. 品牌名「晨露」置于标题首位，未冒用其他品牌词，无侵权风险提示。


```
