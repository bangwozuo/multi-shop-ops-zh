## 能力描述

库存低于阈值即推送。按净可用口径逐 SKU 两级判定，输出可核对的预警清单：

1. **R1 超卖风险** —— 可用库存 - 在途订单 < 0（净可用为负），级别「紧急」，建议 2 小时内处置
2. **R2 低库存预警** —— 净可用 ≥ 0 且可用库存 < 安全水位线，级别「高」
3. **R3 快照体检** —— 快照延迟 > 60 分钟、水位线缺配的 SKU 显式标注，不估算不补零

单轮扫描 ≤ 500 个 SKU；紧急级置顶。`scripts/alert_scan.py` 承担净可用计算、
两级判定、水位偏离与产物落盘。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `metrics` | object | ✅ | 经营数据（流水、客流、订单等） |

## 输出规格

异动检测与预警

- `alerts`：命中的异常及级别
- `no_alert`：已检查但正常的指标
- `need_confirm`：数据不足或规则未覆盖的部分

### 脚本产物（out/）

| 文件 | 内容 |
|---|---|
| `out/预警清单.csv` | 逐条判定（指标/当前值/基线/偏离/级别/判定规则） |
| `out/超卖预警报告.md` | 预警清单 + 未命中项 + 需人工确认 |
| `out/alerts.json` | 机器可读结果，供工作流与下游技能读取 |

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：带脚本（推荐，产出真实文件）

```bash
python <SKILL_DIR>/scripts/alert_scan.py --input examples/input.json --outdir out
python <SKILL_DIR>/scripts/alert_scan.py --demo --outdir out      # 无输入也能看效果
```

**分工**：脚本做净可用计算、两级判定、水位偏离、产物落盘；
模型做补货紧迫度措辞、处置窗口建议、与运营确认口径。数值一律以脚本输出为准。
