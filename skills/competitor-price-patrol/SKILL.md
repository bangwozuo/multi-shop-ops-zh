## 能力描述

竞品价格/促销异动检测。按量化三级阈值逐 SKU 判定，输出可核对的预警清单：

1. **R1 降价异动** —— 偏离 ≤ -8%（vs 7 日均价），级别「高」
2. **R2 关注** —— 偏离 -5%~-8%，级别「中」；**R3 涨价异动** —— 偏离 ≥ +8%，级别「中」
3. **R4 大促标记拦截** —— 命中百亿补贴/限时直降/秒杀等标记，无论偏离幅度一律附加「需人工确认」

偏离 =（当前价 - 7日均价）÷ 7日均价 × 100%；单轮巡检监控 SKU ≤ 50 个。
`scripts/patrol.py` 承担偏离率计算、三级判定、大促标记拦截与产物落盘。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |

| `metrics` | object | ✅ | 经营数据（流水、客流、订单等） |

## 输出规格

异动检测与预警

- `alerts`：命中的异常及级别
- `no_alert`：已检查但正常的指标
- `need_confirm`：数据不足或规则未覆盖的部分

| 文件 | 内容 |

| `out/patrol.json` | 机器可读结果，供工作流与下游技能读取 |

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：带脚本（推荐，产出真实文件）

```bash
python <SKILL_DIR>/scripts/patrol.py --input examples/input.json --outdir out
python <SKILL_DIR>/scripts/patrol.py --demo --outdir out      # 无输入也能看效果
```

**分工**：脚本做偏离率计算、三级阈值判定、大促标记拦截、产物落盘；
模型做动机解读、跟进方向撰写、与运营确认口径。数值一律以脚本输出为准。
