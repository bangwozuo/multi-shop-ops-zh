## 能力描述

跨平台类目/规格对照。按三级规则逐条建立源条目 → 目标类目的映射，输出可核对的映射表：

1. **R1 同名/同义词命中** —— 置信度「高」，匹配依据写明对应关系（如 保温杯 → 餐饮具/水杯/保温杯）
2. **R2 语义近似** —— 置信度「中」，涉及儿童用品资质/食品接触材质的必须标注人工确认
3. **R3 无匹配** —— 置信度「不映射」，进未匹配项并给建目建议，禁止强行映射

配套约束：单次映射源条目 ≤ 200 条；「高+中」置信占比 < 80% 时提示分批人工复核。
`scripts/match_map.py` 承担确定性匹配（同义词规则 + bigram 相似度，阈值 0.8/0.5）与产物落盘。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `source_set` | string | ✅ | 需要被映射的条目 |
| `target_set` | string | ✅ | 映射的目标体系或清单 |

## 输出规格

映射与配对

- `mapping`：逐条给出对应关系
- `unmatched`：两侧无法对应的条目
- `suggestions`：对未匹配项的建议做法

### 脚本产物（out/）

| 文件 | 内容 |
|---|---|
| `out/映射表.csv` | 逐条映射（源条目/目标条目/匹配依据/置信度） |
| `out/映射报告.md` | 映射表 + 未匹配项 + 处理建议 |
| `out/mapping.json` | 机器可读结果，供工作流与下游技能读取 |

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：带脚本（推荐，产出真实文件）

```bash
python <SKILL_DIR>/scripts/match_map.py --input examples/input.json --outdir out
python <SKILL_DIR>/scripts/match_map.py --demo --outdir out      # 无输入也能看效果
```

**分工**：脚本做确定性匹配、置信度分级、双向未匹配盘点、产物落盘；
模型做业务语境解释、资质确认提示、建目建议措辞。数值一律以脚本输出为准。

### 方式三：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）
